# Re-layout (w4jxq) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace c43's cell-based `layout` command with a Rust translation of the c43-router layout engine (new library crate `c43-layout`), and render `c43 system|container` as drawio via a new `--drawio` option.

**Architecture:** `packages/c43-layout` is a pure library: compound graph + hints in, layout + metrics out, no text and no rendering. It is a line-by-line translation of `../c43-router/src` (pinned at commit `48b6428`). Text measurement (`text.ts`), the header band and the drawio export move to c43, which builds graph and hints from the C4 document. Golden fixtures are produced once by the TS engine and checked into the repo before c43-router is deleted.

**Tech Stack:** Rust 2021, serde/serde_json (`preserve_order`), indexmap, clap 4; Node ≥25 (runs `.ts` directly) only for the one-off golden generator.

**Spec:** `.moth/doing/w4jxq-med-re_layout.md` (Decisions section). TS source of record: `/home/doo/projects/c43-router/src/*.ts` and `test/*.test.ts` @ `48b6428`.

## Global Constraints

- Translation, not reimplementation: every TS function gets a Rust counterpart with the same name in snake_case, same branch structure, same constants. No TS line references in Rust comments; doc comments carry over (translated).
- No `HashMap`/`HashSet` iteration may influence output. Use `IndexMap`/`IndexSet` (insertion order = JS `Map`/`Set`), and `shift_remove` (never `swap_remove`) where TS deletes from an ordered collection.
- `Math.round(x)` → `js_round(x) = (x + 0.5).floor()` (JS rounds .5 toward +∞; Rust `round` does not).
- `Math.max(...xs)` with possibly empty `xs` → fold starting at `f64::NEG_INFINITY` (or the literal TS seed such as `Math.max(0, ...)` → fold from 0).
- JS `Array.prototype.sort` is stable → `sort_by` (stable). Comparators `a - b || c - d` → `partial_cmp().then_with()`.
- Numbers printed into drawio go through `js_num(f64) -> String`: integers without `.0`, `-0` → `0`, otherwise Rust `{}` (shortest round-trip, same as JS for the magnitudes we produce).
- Unknown id in hints → error. More than one priority placement hint → error (placement hints themselves are m1ei4; this task rejects a non-empty `placement` list with `placement hints not supported yet`).
- `--drawio`: XML to stdout, violations as `warning: <rule>: <detail>` on stderr, exit 0; non-zero only when generation is impossible.
- TypeScript style rules from CLAUDE.md apply to the TS golden generator (functional array style).
- A task is done only when `npm run build` (root) and `npm run e2e` (packages/example/local-docker) pass.

## Review Focus

1. **C4 doc with no nodes besides the system** (`c43 container packages/example/local-docker` today): engine requires ≥1 node, so c43 must not call it. Expected: drawio with frame + title only, exit 0, stderr `warning: nothing to lay out`. Test in Task 11.
2. **Relations the engine rejects** (self-loop, member → own ancestor group, endpoint uid missing from nodes, node contained twice): c43 drops/repairs them with a stderr warning instead of failing. Test in Task 10.
3. **Labels with `& < > "` and non-ASCII** in node, group, title: escaped in XML; width estimate iterates code points like JS `for…of`. Test in Task 11.
4. **Same pair with several `is` kinds and labels shown only when >1 distinct non-contains kind**: one edge, labels joined `", "` in first-seen order. Test in Task 10.
5. **Container-sized input performance**: rebob-container must finish well under the TS time (TS ~60 s). Golden test asserts < 60 s in release (`cargo test --release`). Test in Task 9.

### Engine API (produced in Task 2, used everywhere)

```rust
// packages/c43-layout/src/model.rs — public input
#[derive(Deserialize, Serialize, Clone, Default)]
pub struct InputGraph {
    pub title: Option<String>, pub description: Option<String>,
    #[serde(default)] pub groups: Vec<InputGroup>,   // { id, label?, group? }
    pub nodes: Vec<InputNode>,                       // { id, label?, group? }
    #[serde(default)] pub edges: Vec<InputEdge>,     // { from, to, label? }
}
#[derive(Deserialize, Serialize, Clone, Default)]
pub struct Hints {
    #[serde(default)] pub kinds: Vec<KindHint>,          // { from, to, kind: "data"|"nf" }
    #[serde(default)] pub placement: Vec<serde_json::Value>, // m1ei4; must be empty for now
    #[serde(default)] pub sizes: SizeHints,
}
#[derive(Deserialize, Serialize, Clone)]
#[serde(rename_all = "camelCase")]
pub struct SizeHints {
    #[serde(default)] pub node: IndexMap<String, f64>,        // min node side per node, grid units (default 1)
    #[serde(default)] pub group_title: IndexMap<String, f64>, // title width per group, grid units (default 0)
    #[serde(default = "one")] pub title_height: f64,          // group title line height, grid units (TS: 1)
}
pub struct Options { pub patience: usize }                    // default 40
pub struct LayoutResult { pub layout: Layout, pub metrics: Metrics } // Serialize
pub fn layout(g: &InputGraph, h: &Hints, o: &Options) -> Result<LayoutResult, String>;
```

Internal `Graph`/`Node` keep `kind` (as in TS) because `hier.rs` builds macro graphs with explicit node kinds; only the public normalize derives it: node kind = `nf` iff no data edge touches it; edge kind = matching kind hint, else `data`.

Output `Layout` = TS `Layout` without `unitPx`, `fonts`, `header`, `nodes[].lines`; `frame` = grid only `{x:0,y:0,w:gridW,h:gridH}`; plus `title`/`description` echoed; `edges[].label` echoed when set; top-level `"version": 1` in `LayoutResult`.

Text replacement map (TS → hint, all at unitPx 20):

| TS | engine |
|---|---|
| `labelSide(labels, unitPx)` | `max(sizes.node[*], 1)` |
| `titleColsFor(unitPx, minS)(label)`: smallest c with `(c·minS + 3(c−1) + 2)·unitPx ≥ textWidth(label,12,bold) + 6 + unitPx` | smallest c with `c·minS + 3(c−1) + 2 ≥ groupTitle[id] + 1` |
| group title `w = min(r.w − 1, ceil((textWidth + 6)/unitPx))` | `min(r.w − 1, ceil(groupTitle[id]))` |
| `TITLE_SLOTS(unitPx) = ceil(12·1.25/unitPx) + 1` | `title_height.ceil() + 1` |
| `header(...)`, `labelLines(...)`, `fonts` | moved to c43 renderer |
